H1|1. Introducción
P|SPORTFORCE 3D es una aplicación de escritorio para vender ropa deportiva. El **cliente** mira el catálogo, personaliza uniformes en un diseñador (foto realista y persona en 3D), compra y registra su pago con Yape, Plin o transferencia. El **administrador (ADMIN)** revisa y aprueba los pagos, cambia el estado de los pedidos, mantiene los productos y el stock, y saca reportes de ventas. Todo funciona en la misma computadora: los datos se guardan en un archivo de base de datos local, sin internet.
P|Este manual muestra cada pantalla con una captura real. Cada botón, campo o pestaña lleva un **círculo rojo numerado** fuera de la imagen y una **flecha** que lo señala; la tabla de debajo explica para qué sirve cada número. Las marcas "solo ADMIN" y "pide confirmación" indican que el botón está reservado al administrador o que la aplicación pregunta antes de hacer el cambio. La sección 6 resume una compra completa citando los números de las figuras.

L|2.|En el asistente pulsa **Next**, deja la carpeta propuesta (C:\Program Files\SPORTFORCE 3D\) y pulsa **Install** y luego **Finish**. El instalador ya trae Java: no hay que instalar nada más.
L|3.|Abre la aplicación desde **menú Inicio › SPORTFORCE 3D**. La primera vez se crea la base de datos con productos de ejemplo en %APPDATA%\SportForce3D\data\sportforce3d.db.
L|4.|Para probarla usa las cuentas de la tabla. Desde el código fuente se abre con **mvnw.cmd javafx:run** (ver el documento "Para ejecutar").

H1|6. Cómo hacer una compra
L|1.|**Inicia sesión.** Escribe tu correo y contraseña en el [[l_correo]] y el [[l_pass]], y pulsa el [[l_entrar]]. Si no tienes cuenta, pulsa el [[l_registro]].
L|2.|**Busca el producto.** Abre el catálogo con el [[s_catalogo]] o escribe en el [[s_buscar]] y pulsa Enter. Filtra con el [[c_cat]] y abre el producto con el [[c_card]].
L|3.|**Elige color, talla y cantidad** con el [[f_color]], el [[f_talla]] y el [[f_mas]]. Pulsa el [[f_agregar]].
L|4.|**(Opcional) Personaliza el uniforme.** Pulsa el [[f_personalizar]], cambia colores, nombre y número, guarda con el [[d_guardar]] y agrégalo con el [[d_carrito]].
L|5.|**Revisa el carrito.** Ábrelo con el [[s_carrito]], ajusta las unidades con el [[k_mas]] y pulsa el [[k_pagar]].
L|6.|**Finaliza la compra.** Elige la dirección con el [[o_dir]] (o crea otra con el [[o_nuevadir]]), elige Yape con el [[o_yape]], escribe una nota opcional en el [[o_notas]] y pulsa el [[o_confirmar]]. El pedido queda "Pendiente de pago" y el stock reservado.
L|7.|**Paga y registra el pago.** En el detalle del pedido aparecen el monto y el número de Yape, Plin o la cuenta. Paga desde tu app, escribe el código en el [[p_codigo]], elige la captura con el [[p_elegir]] y pulsa el [[p_enviar]]. El pedido pasa a "Pago en verificación".
L|8.|**Verificación del ADMIN.** El administrador compara el código y el comprobante y pulsa el [[a_aprobar]]. El pedido pasa a "Pagado" y se descuenta el stock. Ningún pedido se marca como pagado sin esta revisión.
L|9.|**Seguimiento.** El ADMIN avanza el pedido con el [[a_estado]] y el [[a_cambiar]] (En producción › Enviado › Entregado). Tú ves cada cambio abriendo el pedido con el [[m_fila]].

H1|7. Errores comunes
TABLE|3000,6026
T|Problema|Solución
T|"Demasiados intentos" al iniciar sesión|Tras 5 contraseñas incorrectas el correo se bloquea 5 minutos. Espera y revisa mayúsculas y la tecla Bloq Mayús.
T|"Agregar al carrito" no se puede pulsar|Primero elige una talla. Si la talla no tiene stock, elige otra o espera a que el ADMIN reponga el inventario.
T|"Confirmar pedido" muestra un error|Falta elegir una dirección o hay productos "no disponibles" en el carrito: quítalos y vuelve a intentar.
T|No se acepta el comprobante|El código debe tener de 4 a 40 caracteres y no estar usado en otro pago; el archivo debe ser PNG, JPG o PDF de hasta 5 MB.
T|La Vista 3D tarda o muestra un maniquí|La primera carga de cada persona tarda unos segundos. Si falta el modelo 3D se ve el maniquí de respaldo; actualiza los controladores de video.
ENDT|
